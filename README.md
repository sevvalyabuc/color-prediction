# Color Guessing Game

A Windows Forms game built with C#, where the player tries to match a hidden target color by adjusting RGB values.

---

## 🎮 How It Works

- The game picks a **target color**.
- The player adjusts the **R, G and B sliders** to build a color.
- The **Selected Color** preview updates live as the sliders move.
- Pressing **Guess** submits the guess and scores it.
- The player has **10 attempts** per game and earns points.
- **New Game** starts a fresh round.

## ✨ Features

- Interactive RGB sliders with live color preview
- Attempt counter and score tracking
- Dark themed Windows Forms interface
- Turkish user interface
